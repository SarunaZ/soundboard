## Device and artifact limits

- An API 36 `sdk_gphone64_x86_64` emulator with 4 KiB pages is available in prior QA evidence. The bounded Samsung Galaxy S24 Ultra run used Android 16/API 36 with 4,096-byte pages. Neither verifies runtime behavior on a 16 KiB page-size device.
- APK ELF alignment checks and `zipalign -c -P 16 -v 4` establish artifact structure; neither substitutes for running on a real 16 KiB device.
- A valid prior snapshot or pending transaction can recover. If both committed snapshots/journal are corrupt, the app fails closed and preserves files. The current Settings backup/import merge path cannot repair unreadable current metadata; a manual support/export recovery procedure remains open.
