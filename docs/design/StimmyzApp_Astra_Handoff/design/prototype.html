Interactive UX prototype

Astra design reference. Explore the app using the phone mockup. All behavior is simulated — no audio is downloaded, recorded, trimmed, persisted or uploaded.

Try these interactions

  • Switch soundboards from the layout selector.
  • Open a pad's ⋮ menu and choose Replace / Move / Clear.
  • Open Quick add, or change its preferred action with the small chevron.
  • In Library, open a ⋮ item menu.
  • Use the Editor tab or Quick add to start Source → Trim → Customize.
  • Drag waveform handles; expand Fine tune.
  • Pick default artwork, mock image search or a device image for local preview.
  • Toggle Dark / Light via Preferences.

Design constraints

One shared full-screen creation flow; minimal controls; artwork optional; supported media sources vary by distribution. This prototype is separate from the production Android app.
