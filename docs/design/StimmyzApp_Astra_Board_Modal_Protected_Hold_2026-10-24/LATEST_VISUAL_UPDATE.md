# October 24 visual update

The approved transparent `Stimmyz ✦` logo stays unchanged. Editor's redundant heading/subheading removed; Library heading/subheading and create CTAs removed. GIPHY was retired, replaced with Default/Open gallery using only the Android system picker. Newly created pads get saved unique-ish colorful RGB/pastel gradients. Theme selection is solely Settings → Appearance. Old Coffee palette is labeled Chocolate and new dark choices Grape, Nut, and Blackberry join the five light themes.
